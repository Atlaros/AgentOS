# Factory Agent OS

Fábrica de agentes para emprendedores, pymes y medianas empresas. Cada negocio arma sus flujos con los nodos de la plataforma; sus empleados digitales atienden, venden y cobran por WhatsApp junto al equipo humano. Primeros rubros: cafeterías y tiendas de ropa.

```bash
uv sync --extra dev && .venv/bin/pytest -q
```
